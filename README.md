## Getting Started

1、json生成：dart run build_runner build  
2、splash生成：dart run flutter_native_splash:create  
3、数据库对象生成：flutter packages pub run build_runner build --delete-conflicting-outputs  
3、查看依赖问题：flutter pub deps
