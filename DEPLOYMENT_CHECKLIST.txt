浮光掠影官网上线前检查

1. 在腾讯云确认并购买最终域名，优先检查 hsmovie.cn，其次 hsmovie.com。
2. 确认域名实名认证主体与阿里妈妈账号实名主体一致。
3. 向腾讯云确认 EdgeOne Makers 是否可作为 ICP 备案接入资源；不满足时准备合规备案资源或授权码。
4. 完成 ICP 备案后，将备案号和工信部链接加入 index.html 页脚。
5. 创建并验证 support@最终域名，替换三个 HTML 文件中的 support@hsmovie.cn（若最终域名不同）。
6. 在 EdgeOne Makers 中仅授权 GitHub 仓库 xmutzlq/hsmovie。
7. 使用 main 分支；静态站无安装和构建命令；输出目录为仓库根目录。
8. 绑定 www 子域名并启用 HTTPS；根域名 301 跳转到 www。
9. 检查首页、隐私政策和用户协议均可直接打开，且没有 404、证书或混合内容错误。
10. 阿里妈妈“官方地址”填写 https://www.最终域名/，不要填写 GitHub 或 EdgeOne 预览地址。
11. 正式提交前删除首页和政策页中“域名启用后生效”“完成备案后补充备案号”等待办提示。
12. 核实影视信息、图片、媒体资源和推广方式具备所需权利或授权材料。
